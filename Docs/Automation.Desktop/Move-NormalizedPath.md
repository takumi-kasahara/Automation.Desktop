# Move-NormalizedPath

## SYNOPSIS

Moves items using normalized paths.

## SYNTAX

### PathSet (Default)

```
Move-NormalizedPath [-Path] <string[]> [-Recurse] [-Force] [-PassThru] [-WhatIf] [-Confirm]
```

### LiteralPathSet

```
Move-NormalizedPath -LiteralPath <string[]> [-Recurse] [-Force] [-PassThru] [-WhatIf] [-Confirm]
```

## ALIASES

This cmdlet has the following aliases,
{{Insert list of aliases}}

## DESCRIPTION

Resolves each specified path, normalizes the final path component, and moves the item to the normalized destination when the path changes.
Supports wildcard and literal paths.

## EXAMPLES

### EXAMPLE 1

```powershell
Move-NormalizedPath -Path 'C:\dir\*' -WhatIf
```

Shows how matching paths would be renamed to their normalized forms.

### EXAMPLE 2

```powershell
Move-NormalizedPath -LiteralPath 'C:\dir\file.txt' -Force
```

Moves file.txt to its normalized path, bypassing confirmation if the file already exists.
